# JavaScript Exercises

A collection of introductory JavaScript course exercises, organized by Git branch.

| Branch | Exercise |
| --- | --- |
| `desafio2` | Classes, form events and in-memory objects |
| `Desafioo1` | Early course exercise |
| `DesafioLibrerias` | Libraries exercise |
| `desafioFetch` | Fetch API exercise |

Switch to the relevant branch and inspect its HTML and JavaScript files. These are learning examples, not deployed applications. Do not enter real account credentials in the form exercise.
